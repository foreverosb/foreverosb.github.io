TAM Drive Sync는 운영자 본인의 GitHub 문서를 지정한 Google Drive 폴더로 복사하는 개인용 자동화 도구입니다.

GitHub → Google Drive

기본 브랜치의 Markdown, 텍스트, PDF, Word 문서를 원래 폴더 구조대로 복사합니다. 문서 변경 시와 정기 점검 시 실행하도록 구성합니다.

동작 방식

  • 사용자가 직접 Google OAuth 인증을 승인한 뒤 GitHub Actions에서 실행합니다.
  • 대상 폴더의 파일 이름·체크섬·동기화 메타데이터를 확인하고 필요한 파일을 생성하거나 업데이트합니다.
  • Drive에서 수정된 파일과 충돌하면 덮어쓰기를 중단합니다.
  • GitHub에서 삭제된 파일도 Drive에서는 자동 삭제하지 않습니다.

Google 데이터 접근 목적

Google Drive 접근은 문서 복사와 변경·충돌 확인에 사용됩니다. 현재 OAuth 구성은 전체 Drive 접근 범위(drive)를 요청하지만, 동기화 코드는 지정된 TAM 폴더 아래에서 작업하도록 제한합니다. 이 코드 제한은 OAuth 권한 자체를 폴더 단위로 제한하는 것은 아닙니다.

이 사이트는 앱 안내용입니다. Google 로그인이나 파일 업로드를 제공하지 않으며, 학습 문서와 인증 정보를 공개하지 않습니다. 일반 사용자를 모집하는 서비스가 아닙니다.
