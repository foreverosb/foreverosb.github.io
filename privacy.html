1. 목적과 적용 범위

TAM Drive Sync는 운영자 본인의 GitHub 문서를 지정한 Google Drive 폴더로 복사하기 위한 개인용 자동화입니다. 이 방침은 해당 자동화와 공개 안내 사이트에 적용됩니다.

2. 처리하는 데이터

  • 원본 GitHub 문서의 내용과 상대 경로
  • 대상 Drive 폴더 및 파일의 ID, 이름, 파일 유형, 체크섬, 동기화 경로와 체크섬을 기록한 앱 메타데이터
  • Google OAuth 클라이언트 정보, 갱신 토큰 및 실행 중 발급받는 접근 토큰
  • 실행 결과와 처리된 파일 경로 등이 포함될 수 있는 GitHub Actions 로그

3. 권한과 사용 목적

현재 구현은 Google Drive 전체 접근 범위(https://www.googleapis.com/auth/drive)를 요청합니다. 실제 동기화 로직은 지정된 TAM 폴더와 그 하위에서 문서를 생성·업데이트하고 변경 여부를 확인하도록 제한합니다. 전체 Drive 권한과 코드의 작업 범위 제한은 서로 다릅니다.

Google 사용자 데이터는 동기화, 충돌 확인 및 오류 해결 목적으로만 사용하며 광고, 판매, 신용평가 또는 범용 AI 모델 학습에 사용하지 않습니다. Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 Limited Use 요건을 포함한 Google API Services User Data Policy를 준수합니다.

4. 저장과 서비스 제공자

원본은 GitHub 저장소에, 복사본은 사용자의 Google Drive에 저장됩니다. 자동화 실행에는 GitHub Actions와 Google API가 사용되므로 실행에 필요한 데이터가 해당 서비스에서 처리됩니다. OAuth 자격증명은 GitHub Actions Secrets에 보관하도록 구성하며 공개 저장소나 이 사이트에 게시하지 않습니다. 다운로드한 OAuth 설정 파일은 사용자 컴퓨터에서 관리합니다.

5. 보관과 삭제

Drive 복사본은 사용자가 삭제할 때까지 남으며 자동화는 원본 삭제를 이유로 복사본을 삭제하지 않습니다. 실행 로그는 저장소의 GitHub Actions 보관 설정을 따릅니다. 인증 정보는 사용자가 Secrets에서 삭제하거나 Google 계정에서 접근을 철회할 때까지 동기화에 사용될 수 있습니다.

6. 접근 철회와 중단

Google 계정의 타사 앱 연결 관리에서 앱 접근을 철회할 수 있습니다. 자동화를 종료하려면 GitHub Actions 워크플로를 비활성화하고 관련 Secrets를 삭제하세요. 이미 생성한 Drive 문서와 로컬 OAuth 설정 파일은 필요에 따라 별도로 삭제해야 합니다. 접근 철회는 기존 문서를 자동 삭제하지 않습니다.

7. 안내 사이트 방문 정보

이 정적 사이트에는 별도의 로그인, 입력 폼, 광고 또는 분석 스크립트가 없습니다. 호스팅 제공자인 GitHub는 서비스 제공 및 보안을 위해 IP 주소 등의 접속 정보를 자체 정책에 따라 처리할 수 있습니다. GitHub 개인정보처리방침을 참고하세요.

8. 문의와 변경

문의는 공개 문의 게시판에서 할 수 있습니다. 비밀키·토큰·개인 문서는 게시하지 마세요. 동작이나 데이터 처리 방식이 변경되면 이 페이지와 시행일을 갱신합니다.
